Why this lesson matters

The first 30 seconds at yum cha go the same way almost every time. Nail them and you start the meal like a local.

🎯 Interaction purpose

You arrive at a busy yum cha restaurant with a friend. The server asks how many people, shows you to a table and asks which tea you'd like. You answer, order a pot and say thank you.

✅ By the end you can…

  • Understand 幾位呀？ gei2 wai6 aa3? and say your party size
  • Ask which teas you can choose from
  • Order one pot of the tea you like
  • Thank the server naturally with 唔該 m4 goi1 / 唔該晒 m4 goi1 saai3
Completion goal: without looking, say your party size, choose one tea and thank the server in a four-line arrival role-play.

🎧 Check your audio settings before recording tap to open
In every step you'll listen to the model, record yourself, then play yours back. You can't move on until each one is done, so set up first:
  1. Allow the microphone. When your browser asks, click Allow. If you clicked Block, use the 🔒 or ⓘ icon by the address bar to turn the microphone back on, then reload.
  2. Pick the right mic. Mac: System Settings → Sound → Input. Windows: Settings → System → Sound → Input. Make sure the level moves when you talk.
  3. Turn the volume up and use headphones if you can, so the playback doesn't echo.
  4. Get a Cantonese voice. The model audio uses your device's Cantonese (Hong Kong) voice. Mac: System Settings → Accessibility → Spoken Content → System voice → Manage Voices → Chinese (Hong Kong). Windows: Settings → Time & language → Speech → Add voices → Chinese (Traditional, Hong Kong SAR). Chrome or Safari work best.
